# Codex Quota Pills Agent instructions

For an explicit install/run request, read README.md, INSTALL.md and install.ps1.
Prefer the verified stable portable Release via the root install.ps1 entry point.
Do not compile source or run developer tests for ordinary installation.
Read scripts before execution; never pipe downloaded text directly into execution.
Reuse verified existing installations and preserve settings, old versions and the
shared automatic continuation ledger. Never downgrade or reset the ledger.
Use the normal executable entry point so its interactive desktop launcher runs.
Report installation, quota connection, running state and actual visibility
separately. A running process is not proof that the pills are visible.
If the tool session cannot see the desktop, use the troubleshooting steps in
INSTALL.md and request an Explorer double-click visibility check when necessary.
Do not modify/restart Codex, expose credentials, or enable automatic messages
without user authorization. Create Startup entries only when the user requests it.
Do not publish changes or releases without an explicit request to publish.
