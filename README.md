# Codex Quota Pills · 额度胶囊

把 Codex 的剩余额度放在工作窗口旁。支持 Windows 版 Codex，可查看 **5 小时额度、周额度、累计 Token、重置券到期时间**，也能按需开启额度恢复续跑和临期自动用卡。

**[下载 v0.2.38 便携版](https://github.com/jinfu0111-gif/CodexQuotaPills/releases/download/v0.2.38/CodexQuotaPills-0.2.38-portable.zip)** · [全部发行版本](https://github.com/jinfu0111-gif/CodexQuotaPills/releases) · [安装与排查](INSTALL.md) · [更新记录](CHANGELOG.md)

![额度胶囊：套餐、5h、周、Token、券](docs/images/composer-pills-preview.png)

适用环境：Windows 10/11、.NET Framework 4.7.2+、已登录的 Windows Codex，以及可用的 `codex app-server`。普通使用无需编译源码或管理员权限。这是独立的社区开源工具，与 OpenAI 无隶属关系。

本文界面图片由 0.2.38 真实控件离屏导出，数字为演示数据；带窗口装饰的定位图片用于说明位置。

## 三分钟开始使用

### 方式一：让 Codex 安装

把下面这句话发给 Windows 本机 Codex：

> 帮我安装并启动 https://github.com/jinfu0111-gif/CodexQuotaPills ，按仓库 INSTALL.md 执行，确认额度连接和胶囊显示是否成功。

安装脚本会下载正式便携包、核对文件摘要，安装到用户目录并创建开始菜单入口。首次安装暂停自动续跑，临期自动用卡默认关闭。需要开机启动，可在请求末尾加上“设置登录 Windows 后自动启动”。

### 方式二：手动解压运行

1. 下载上方 **portable.zip**，解压到长期保留的可写目录。
2. 双击 `CodexQuotaPills.exe`，打开已登录的 Windows Codex。
3. **点击蓝色 `5h` 打开菜单**，调整位置、外观和显示项目。
4. 只想查看额度：进入“任务续跑”，确认处于暂停状态。

**手动首次运行且没有旧续跑记录时，自动续跑默认开启；安装脚本首次安装会预先暂停。** 已有用户的开关会跨版本保留。临期自动用卡是独立开关，默认关闭。

程序会跟随 Codex 启动显示，Codex 退出后收起；菜单“退出程序”会同时停止显示和后台监听。

## 胶囊怎么看

| 胶囊 | 显示什么 | 如何操作 |
| --- | --- | --- |
| 紫色 `PLUS / PRO` | 当前套餐 | 可在显示设置中隐藏 |
| 蓝色 `5h` | 5 小时**剩余**额度 | 点击打开主菜单 |
| 绿色 `周` | 本周**剩余**额度 | 悬停看重置时间和汇总 |
| 橙色 `Token` | 当前账户累计 Token | 点击查看所选会话用量 |
| 粉色 `券` | 可用重置券数量 | 悬停看逐张到期时间 |

剩余不超过 20% 时圆点变橙，用尽变红。`—` 或“待确认”表示数据尚未确认。Pro 在接口确认没有 5 小时限额时显示 `5h ∞`，周额度继续按实际返回显示。

![Pro 显示示例](docs/images/pro-pills-preview.png)

悬停周额度，查看两档额度的重置时间、券汇总及公开重置信息；悬停粉色券，查看每张券的到期时间。时间按本机时区显示，同一时间到期的多张券分别列出。

## 位置与外观

**5h → 显示位置**，选择适合自己的布局：

| 位置 | 使用方式 |
| --- | --- |
| 标题栏 | 横排显示；空间变窄时逐步收起其他项目，优先保留 5h 入口 |
| 输入框 | 放在权限按钮右侧的工具栏空位；整组放不下、被浮层遮挡或没有输入框时隐藏 |
| 侧边栏 | 最左窄栏显示 5h、周两个圆环；点击 5h 打开菜单 |

输入框模式跟随已确认的位置移动，松手后重新定位；调整窗口大小、缩放或布局时会重新确认。空间恢复后自动显示。暂时找不到胶囊，可从**系统托盘 → 返回标题栏**恢复。

![三种位置菜单](docs/images/unified-plus-menu-preview.png)

**5h → 外观主题**可选跟随系统、浅色、深色；**5h → 胶囊显示**可分别隐藏套餐、Token、券。仅保留 5h 和周额度就是极简模式，设置会自动保存。

![极简模式](docs/images/minimal-pills-preview.png)

胶囊跟随 Codex 窗口层级，其他程序可以自然遮住它；最小化或隐藏 Codex 时收起。它是独立覆盖层，不会修改 Codex 页面或挤占原生控件空间。不同客户端布局下，输入框和侧栏的可用位置可能不同。

## 会话用量：Token、缓存与上下文

点击 Token，或进入 **5h → 会话数据**，从列表中选择对话。面板每 15 秒刷新。

![会话用量面板](docs/images/session-usage-preview.png)

- **账户累计 Token**：账户总量。
- **所选会话累计**：所选对话的累计用量。
- **最近请求输入、输出、缓存输入**：最近一次有效请求的统计，缓存输入包含在输入总量内。
- **上下文估算**：最近请求总量与上下文窗口的比例。
- **压缩事件**：本次有限日志扫描中观察到的次数，部分历史会明确标注。

需要手动选择会话，当前版本不会自动认出屏幕上正在看的对话。累计 Token、缓存命中率和上下文占用是不同指标；尚未发送的输入不会计入最近请求。面板只读数据，不主动压缩或发送任务。详见[会话数据说明](docs/session-usage.md)。

## 可选：额度恢复后自动续跑

进入 **5h → 任务续跑**，查看候选任务、暂停或恢复，也可取消单个候选任务。

![自动续跑面板](docs/images/auto-resume-preview.png)

开启后，每 30 秒检查最近的未归档根对话。只有最新执行因 `usageLimitExceeded` 失败，并且实时额度已恢复，才会向原对话发送固定续跑消息；沿用原模型、权限和审批机制。

手动停止、已完成、正在执行、等待审批、子任务和远程任务会跳过。每个失败轮次最多尝试一次，每个对话累计最多 3 次。暂停与取消记录跨重启保存，关闭面板不会暂停功能。

**默认值取决于安装方式**：安装脚本首次安装暂停；手动首次运行且无旧账本时开启；升级保留原开关。真实额度耗尽后自然恢复的完整续跑过程尚未完成端到端验证，当前作为实验功能提供。协议与已检查客户端版本见[兼容性说明](docs/desktop-ipc-compatibility.md)。

## 可选：重置卡到期自动使用

进入 **5h → 重置卡**，主动启用。**默认关闭**，与自动续跑分别设置。

![临期自动用卡面板](docs/images/auto-reset-credits-preview.png)

Codex 和胶囊运行且联网时，每 30 秒检查可用卡片；进入**到期前 10 分钟**的卡片会按到期先后尝试使用，每轮最多一张。面板显示每张卡的到期时间、自动使用时点和最近结果。

使用前复核当前账户、工作区和卡片明细。已手动使用的卡会跳过；官方返回“没有可重置额度”时不消耗卡片，继续检查至到期。未知结果会复用同一次请求的幂等键。暂停会阻止后续请求，已发出的请求仍需等待结果。

电脑休眠、断网或 Codex / 胶囊关闭时不会执行。记录保存在用户目录，升级时保留。当前已验证模拟消费和真实接口调用；已观察到的实卡自动尝试返回“没有可重置额度”，尚未确认真实成功兑换。

## 常见问题

**输入框位置突然不见了？**
检查是否进入设置页、分栏太窄、附件或浮层占用空位。回到聊天、恢复空间后等待重新定位；也可从托盘返回标题栏。

**启动后完全没有胶囊？**
先确认 Windows Codex 已登录并打开，退出其他目录的旧胶囊实例，再启动新版。详细排查与安装参数见 [INSTALL.md](INSTALL.md)。

**Token 显示“待确认”？**
等待下一次刷新。首次零值或正数突然变零会进行二次确认，读取失败不会直接显示成 0。

**重置信息提示了，但额度没变？**
周额度悬停卡和一次性横幅中的 Tibo 信息来自公开公告。账户是否恢复，以实时额度为准；公告本身不会触发续跑。详见[横幅说明](docs/reset-radar-banner-preview.md)。

**如何分享程序？**
直接分享 Release ZIP。正在使用的目录可能包含 `settings.ini`、额度缓存和诊断快照，不适合整目录打包。

## 数据与开源

额度通过本机 `codex app-server` 获取；会话用量读取本机 SQLite 元数据和有限日志中的数字事件。程序不保存认证令牌、Cookie 或浏览器存储，不修改 Codex 安装文件和数据库。自动续跑和临期用卡开启后，会分别发送续跑消息或调用官方用卡接口。

日常显示设置在程序目录；续跑记录位于 `%LOCALAPPDATA%\CodexQuotaPills\AutoResume\ledger.json`，自动用卡记录位于 `%LOCALAPPDATA%\CodexQuotaPills\AutoResetCredits\state.json`。网络访问还包括公开重置信息、GitHub 更新及微软客户端分发服务。详见 [SECURITY.md](SECURITY.md)。
